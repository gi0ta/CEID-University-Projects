# Σύστημα Υποστήριξης Διπλωματικών Εργασιών

## Περιγραφή

Το Σύστημα Υποστήριξης Διπλωματικών Εργασιών είναι μια διαδικτυακή εφαρμογή που διευκολύνει τη διαχείριση των διπλωματικών εργασιών στο Τμήμα Μηχανικών Η/Υ και Πληροφορικής του Πανεπιστημίου Πατρών. Το σύστημα υποστηρίζει τρεις τύπους χρηστών: φοιτητές, καθηγητές και γραμματεία.

## Δομή Βάσης Δεδομένων

Η βάση δεδομένων του συστήματος (`diploma_db`) περιλαμβάνει τους εξής πίνακες:

1. **users**: Βασικές πληροφορίες για όλους τους χρήστες του συστήματος
2. **professors**: Επιπλέον πληροφορίες για τους καθηγητές
3. **students**: Επιπλέον πληροφορίες για τους φοιτητές
4. **thesis_topics**: Θέματα διπλωματικών εργασιών που προτείνονται από καθηγητές
5. **thesis_assignments**: Αναθέσεις θεμάτων σε φοιτητές
6. **committee_members**: Μέλη τριμελών επιτροπών
7. **professor_notes**: Σημειώσεις καθηγητών για διπλωματικές
8. **thesis_grades**: Βαθμολογίες διπλωματικών
9. **thesis_presentations**: Πληροφορίες για παρουσιάσεις διπλωματικών
10. **thesis_files**: Αρχεία που σχετίζονται με διπλωματικές
11. **thesis_external_links**: Εξωτερικοί σύνδεσμοι για διπλωματικές
12. **status_changes**: Ιστορικό αλλαγών κατάστασης διπλωματικών
13. **public_presentation_announcements**: Δημόσιες ανακοινώσεις παρουσιάσεων
14. **examination_protocols**: Πρακτικά εξέτασης διπλωματικών
15. **notifications**: Ειδοποιήσεις χρηστών
16. **gs_documents**: Αρχεία πρακτικών Γενικής Συνέλευσης

    - Προστέθηκε έλεγχος για την ύπαρξη του πίνακα thesis_applications πριν την εκτέλεση ερωτημάτων σε αυτόν.

    - Αντικαταστάθηκε η χρήση των κλάσεων `ThesisAssignment` και `StatusChange` με απευθείας SQL ερωτήματα μέσω PDO για συμβατότητα με την υπάρχουσα δομή του συστήματος.

## Δομή του Έργου

### Βασικοί Φάκελοι

- **assets/**: Στατικοί πόροι
  - **css/**: Αρχεία CSS (style.css)
  - **js/**: Αρχεία JavaScript (main.js)
  - **img/**: Εικόνες και λογότυπα
- **includes/**: Επαναχρησιμοποιήσιμος κώδικας PHP
  - **config/**: Αρχεία ρυθμίσεων (config.php, database.php)
  - **classes/**: Κλάσεις PHP (User.php)
  - **functions/**: Βοηθητικές συναρτήσεις (auth_functions.php)
- **pages/**: Σελίδες της εφαρμογής
  - **auth/**: Σελίδες αυθεντικοποίησης (login.php, logout.php, forgot_password.php)
  - **student/**: Σελίδες για φοιτητές
  - **professor/**: Σελίδες για καθηγητές
  - **secretary/**: Σελίδες για γραμματεία
- **templates/**: Επαναχρησιμοποιήσιμα τμήματα σελίδων (header.php, footer.php, navigation.php)
  - **components/**: Μικρότερα επαναχρησιμοποιήσιμα στοιχεία
- **uploads/**: Αρχεία που ανεβάζουν οι χρήστες
  - **thesis_files/**: Αρχεία διπλωματικών
  - **gs_documents/**: Αρχεία πρακτικών ΓΣ
  - **temp/**: Προσωρινά αρχεία
- **api/**: Endpoints για AJAX αιτήματα

### Βασικά Αρχεία

- **index.php**: Αρχική σελίδα του συστήματος
- **complete_database.sql**: Πλήρες SQL script για τη δημιουργία της βάσης δεδομένων
- **database.sql**: Αρχικό σχήμα της βάσης δεδομένων

## Ανάλυση και Επίλυση Προβλήματος HTTP 500 στο Dashboard Φοιτητή

### Περιγραφή Προβλήματος

Το dashboard του φοιτητή εμφάνιζε σφάλμα HTTP 500 (Internal Server Error) κατά την προσπάθεια φόρτωσης της σελίδας. Το πρόβλημα εντοπίστηκε στην αδυναμία φόρτωσης δυναμικών δεδομένων από το backend API και σε ασυμβατότητες μεταξύ του σχήματος της βάσης δεδομένων και του κώδικα.

### Διαδικασία Διάγνωσης

1. **Ανάλυση Αρχείων Καταγραφής (Logs)**:
   - Εξετάστηκαν τα αρχεία καταγραφής PHP και Apache για να εντοπιστούν τα συγκεκριμένα σφάλματα.
   - Βρέθηκαν σφάλματα σχετικά με την κλάση `Database` που δεν μπορούσε να βρεθεί και με μη υπάρχοντα κλειδιά στο session.

2. **Έλεγχος Δομής Βάσης Δεδομένων**:
   - Διαπιστώθηκε ότι ο πίνακας `thesis_topics` δεν είχε πεδίο `status` αλλά `is_assigned`.
   - Ο πίνακας `thesis_applications` δεν υπήρχε στη βάση δεδομένων.
   - Ο πίνακας `thesis_assignments` είχε πεδίο `status` με διαφορετικές τιμές από αυτές που αναμένονταν από το frontend.

3. **Έλεγχος API Endpoint**:
   - Το endpoint `/api/student/dashboard_data.php` έκανε ερωτήματα σε μη υπάρχοντες πίνακες και στήλες.
   - Υπήρχε ασυμβατότητα μεταξύ των πεδίων που επέστρεφε το API και αυτών που περίμενε το frontend JavaScript.

4. **Έλεγχος Frontend JavaScript**:
   - Το αρχείο `dashboard.js` περίμενε συγκεκριμένα πεδία και τιμές που δεν υπήρχαν στη βάση δεδομένων.

## Εγκατάσταση

1. Εγκαταστήστε το XAMPP ή παρόμοιο περιβάλλον με Apache, MySQL και PHP
2. Κλωνοποιήστε το αποθετήριο στον φάκελο htdocs του XAMPP
3. Εκτελέστε το αρχείο `complete_database.sql` για να δημιουργήσετε τη βάση δεδομένων:
   ```
   sudo /opt/lampp/bin/mysql -u root < complete_database.sql
   ```
4. Εκτελέστε το script `import_data.php` για να εισάγετε τα δεδομένα:
   ```
   sudo /opt/lampp/bin/php import_data.php
   ```

## Χρήστες του Συστήματος

Το σύστημα περιλαμβάνει τους εξής τύπους χρηστών:

1. **Φοιτητές**: Μπορούν να αναζητούν θέματα, να υποβάλλουν αιτήσεις για ανάθεση, να ανεβάζουν αρχεία και να παρακολουθούν την πρόοδο της διπλωματικής τους.
2. **Καθηγητές**: Μπορούν να προτείνουν θέματα, να αναθέτουν διπλωματικές, να προσκαλούν μέλη επιτροπών, να βαθμολογούν και να παρακολουθούν την πρόοδο των διπλωματικών που επιβλέπουν.
3. **Γραμματεία**: Μπορεί να διαχειρίζεται όλες τις διπλωματικές, να καταχωρεί βαθμούς, να δημιουργεί ανακοινώσεις και να διαχειρίζεται τα αρχεία των πρακτικών ΓΣ.

   - Ειδοποιήσεις για αλλαγές κατάστασης διπλωματικών

6. **Βελτιστοποίηση της διαχείρισης αρχείων**:
   - Ανέβασμα τελικών αναφορών διπλωματικών
   - Ανέβασμα πρακτικών βαθμολόγησης

7. **Δοκιμές και βελτιστοποίηση**:
   - Διεξαγωγή ελέγχων ασφαλείας
   - Βελτιστοποίηση ερωτημάτων SQL
   - Διόρθωση υπολοίπων σφαλμάτων

8. **Ολοκλήρωση Ροής Άμεσης Ανάθεσης Θέματος από Καθηγητή**:
   - Εμφάνιση λίστας διαθέσιμων (μη ανατεθειμένων) θεμάτων στη σελίδα `assign_topic_list.php` που έχουν δημιουργηθεί από τον συνδεδεμένο καθηγητή.
   - Δημιουργία σελίδας (π.χ., `assign_student_to_topic.php`) όπου ο καθηγητής, αφού επιλέξει θέμα:
     - Θα βλέπει τις λεπτομέρειες του θέματος.
     - Θα μπορεί να αναζητήσει φοιτητή (με ΑΜ ή ονοματεπώνυμο).
     - Θα μπορεί να πραγματοποιήσει την προσωρινή ανάθεση του θέματος στον φοιτητή.
     - Θα έχει τη δυνατότητα αναίρεσης αυτής της προσωρινής ανάθεσης.

## Γνωστά Προβλήματα

1. **Προβλήματα με τη σελίδα προβολής λίστας διπλωματικών**:
   - Η σελίδα thesis_list.php για τους καθηγητές δεν φορτώνει σωστά τις διπλωματικές εργασίες
   - Το API endpoint api/professor/thesis_list.php ενδέχεται να έχει ασυμβατότητες με τη δομή της βάσης δεδομένων
   - Πιθανή αιτία είναι οι αναφορές σε πίνακες ή στήλες που δεν υπάρχουν ή έχουν αλλάξει όνομα

2. **Αναφορές σε πίνακες που δεν υπάρχουν**:
   - Έχουν εμφανιστεί σφάλματα HTTP ERROR 500 λόγω αναφορών σε πίνακες που δεν υπάρχουν ακόμα (π.χ. thesis_requests, committee_members)
   - Απαιτείται έλεγχος της συμβατότητας του κώδικα με την τρέχουσα δομή της βάσης δεδομένων

3. **Προβλήματα με τη σύνδεση στη βάση δεδομένων**:
   - Ενδέχεται να υπάρχουν προβλήματα με τη σύνδεση στη βάση δεδομένων λόγω λανθασμένων παραμέτρων σύνδεσης
   - Απαιτείται έλεγχος των παραμέτρων σύνδεσης στο αρχείο includes/config/database.php
